# NLP Laboratory: Python Practical Collection

## About this repository

This project contains the practical work prepared for the Natural Language Processing laboratory
at the Department of Artificial Intelligence, Noida Institute of Engineering and Technology,
Greater Noida. It brings together **32 Python implementations**, beginning with basic text
cleaning and ending with transformer-based applications.

The experiments are grouped into three Course Outcome sections. Every numbered file is designed
to demonstrate a particular idea, use the data supplied in this repository where needed, and
display its result when launched from the command line.

## Installation

Python 3.10 or later is recommended. A virtual environment keeps the laboratory packages
separate from other Python projects:

```bash
python -m venv .venv
```

Activate the environment with the command for your operating system:

```bash
# Windows
.venv\Scripts\activate

# Linux or macOS
source .venv/bin/activate
```

Install the libraries used by the introductory and classical exercises:

```bash
pip install nltk spacy numpy pandas scikit-learn gensim textblob vaderSentiment
```

The deep-learning and transformer examples additionally use the following packages:

```bash
pip install tensorflow torch transformers sentencepiece
```

NLTK data, spaCy language models, word vectors, and Hugging Face models may need to be downloaded
separately. Follow the download instructions shown in each program. The transformer exercises
can require a large amount of storage and may take time to initialize on their first run.

## Executing the programs

Open a terminal at the top level of the repository and run any desired file. Examples:

```bash
python CO1/04_pos_tagging.py
python CO2/19_opinion_mining.py
python CO3/29_text_summarization.py
```

Most programs print a readable report to the console. Additional artifacts are written to or
already available in `outputs/`, including:

- processed text and program summaries;
- Bag-of-Words and TF-IDF CSV matrices;
- embedding and attention plots;
- extracted JSON and CSV information;
- entity visualizations in HTML;
- classified and separated documents.

The files in `data/` are used as small demonstration inputs. The CSV datasets can be regenerated
with:

```bash
python data/generate_datasets.py
```

## Important considerations

1. The supplied datasets are intentionally compact, allowing most demonstrations to complete
   quickly on a normal computer.
2. Accuracy, topic assignments, and other numerical values may differ across random seeds,
   operating systems, and versions of the installed libraries.
3. RNN, LSTM, attention, and transformer tasks generally need more memory and processing time
   than the introductory NLP scripts.
4. Models such as BERT, GPT-2, GloVe, Marian/T5, BART, and DialoGPT may be downloaded when the
   related program is started.
5. A GPU is optional, but it can reduce the execution time of the larger neural-network examples.

## Learning outcomes represented

- **CO1:** Build a foundation in tokenization, normalization, word reduction, grammatical tagging,
  parsing, chunking, and named-entity identification.
- **CO2:** Practice numerical text representation, similarity measurement, language modeling,
  classification, sentiment and opinion analysis, topic discovery, retrieval, extraction, and
  recurrent neural sequence processing.
- **CO3:** Apply current transformer workflows to classification, embeddings, text generation,
  entity recognition, translation, summarization, conversation, and document separation.

This repository is intended to support classroom practice, experimentation, and submission of
the NLP laboratory exercises.
